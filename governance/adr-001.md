# ADR-001: Selection of Dual-Tier Caching Architecture for Routing Matrix

* **Status:** Accepted
* **Context:** Route decisions require evaluation of tenant policy and model health within < 5ms.
* **Decision:** Implement L1 In-Memory TTL Cache (5s) backed by L2 Redis Cluster.
* **Consequences:** Near-zero latency for hot paths with sub-second synchronization across instances.
